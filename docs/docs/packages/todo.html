Tasks

Claude Code-style task tracking with dependencies, a live task widget, and shared task lists.

What it does

Pi-tasks gives Pi a structured way to track multi-step work. It adds task tools modeled on Claude Code's (TaskCreate, TaskList, TaskUpdate, and friends), and a live widget above the editor shows each task as pending, in progress, or done, with elapsed time and token counts for active work.

Tasks can block one another, so Pi knows what has to finish before the next step can start. Task lists persist per session by default and survive resume; they can also be shared across Pi sessions in the same project for coordinated multi-agent work.

Why it's included

Without explicit task tracking, long multi-step work tends to lose coherence — Pi can forget what's done, what's next, or what was deprioritized. A persistent, visible task list keeps both you and Pi oriented, especially when context windows fill and conversations get compacted.

Pi-tasks replaces pi-manage-todo-list, which its author has deprecated. Running npx @robzolkos/lazypi update migrates existing installs automatically.
